# 报告规范核查

按研究类型、稿约和实际适用版本选择规范。以下是检索入口与审读主题，不替代原始清单，也不把清单完整性等同于低偏倚或方法学有效。

## 选择与版本

[EQUATOR](https://www.equator-network.org/) 提供按研究类型检索的规范与扩展入口，可用于找到本次应读的原件。

| 类型 | 通常需要核对的规范入口 |
|---|---|
| 随机试验及方案 | CONSORT、SPIRIT 与适用扩展 |
| 观察性研究 | STROBE 及相应扩展 |
| 系统综述/范围综述/综述方案 | PRISMA、PRISMA-ScR、PRISMA-P 等适用类型 |
| 诊断/预测研究 | STARD、TRIPOD 及适用扩展 |
| 病例报告 | CARE；外科等专属扩展按本次要求 |
| 质性研究 | SRQR 或适用的 COREQ |
| 质量改进 | SQUIRE 及适用扩展 |
| 动物研究 | ARRIVE |
| 临床指南 | 核对 AGREE 与 RIGHT 各自承担的评价或报告用途 |

CONSORT 与 SPIRIT 已有 2025 版，不能固定沿用旧版条目而称已核当前要求。使用时仍需查本次期刊采用的版本和适用扩展。[官方发布页](https://www.consort-spirit.org/published-statements)

## CARE 的顶层主题

2013 CARE 清单的十三个顶层主题包括：题名、关键词、摘要、引言、患者信息、临床发现、时间线、诊断评价、治疗干预、随访与结局、讨论、患者视角及知情同意。尤其不能遗漏第 13 项；子条目、措辞和适用判断回到[官方清单](https://www.care-statement.org/checklist)。

本表是摘要而非完整清单。审读真实稿件时逐项对应原件，记录已报告内容及缺口，不根据此处摘要虚构具体行号或将每个不适用子条目都判作缺失。

## 逐条对照

1. 确认研究类型、规范名称、版本、扩展与来源日期。
2. 作者有随稿清单时提取其标注；无清单时可核正文的适用主题，说明未收到清单。
3. 在实际稿件版本中定位相关内容，区分未报告、未实施、未提供和不适用。清单行号有系统偏移时先核对版本并按内容定位。
4. 判断缺口对可理解性、复核和主要结论的影响，再提出修改；不能仅凭行号错位指控套用他稿。

| 条目与版本 | 原件要求摘要 | 作者标注 | 实际内容与位置 | 状态与影响 | 建议 |
|---|---|---|---|---|---|
| 按本次原件填写 | 不复制成固定检查题库 | 原标注或未提供 | 实际证据 | 已报告/部分/未报告/不适用/未能核对 | 可执行措施 |

可由作者补充的报告问题进入给作者意见。编辑还需要了解的推荐理由或保密完整性线索另列；两种通道不能让应向作者说明的报告缺口消失。

上述官方入口于 2026-10-18 查阅。每次正式任务核对当时适用要求，不能把本次访问日期当作永久有效的版本保证。
