# 按设计选择审稿检查

本清单提供需要判断的问题，不要求每篇论文完成所有设计专属项目。先确定实际研究类型、材料范围及期刊要求，再定位缺口。未报告、未实施、未提供材料和不适用分别说明。

## 通用检查

- 问题、目的、设计、对象、分析单位、主要结局与结论是否相符。
- 纳入排除、招募、实施过程、数据来源、测量与时间点是否足够复核。
- 分母、缺失、重复记录、脱落与分析样本是否交代清楚。
- 数据、表图、摘要与正文之间是否一致；效应量、区间和统计判断是否准确。
- 结论是否超出因果、人群、场景或随访范围；负面结果与不良事件是否完整。
- 伦理或豁免、同意、隐私、资金、贡献、利益关系与工具使用声明是否按适用要求报告。

## 研究设计专项

| 类型 | 本轮重点 |
|---|---|
| 随机试验 | 随机化、分配隐藏、分析集、脱落、结局预设与注册信息；整群试验另查聚类 |
| 队列/病例对照/横断面 | 来源与选择、时序、混杂与偏倚、测量、调整依据和结果外推 |
| 诊断研究 | 指标试验与参考标准、阈值、盲法、样本流向及适用准确性指标 |
| 预测/AI 模型 | 数据划分与泄漏、训练和评价单位、验证、校准、区分度、更新和使用场景 |
| 系统综述/Meta 分析 | 检索与筛选、范围、偏倚评估、合并依据、异质性与敏感性；不强求不适用的分析 |
| 范围/叙述综述 | 目的与范围、来源选择透明度、综合逻辑、分歧及观点依据；不套完整 Meta 框架 |
| 病例报告/病例系列 | 实际过程、时间、选择理由、结局、不良事件与适用报告条目；不以个例证明普遍机制 |
| 问卷/量表研究 | 构念与对象、开发或选择依据、测量属性及适用性；不以单个 α 系数替代全部效度 |
| 德尔菲/专家咨询 | 专家遴选、轮次、反馈、共识定义、条目变化与退出；共识不替代效度或临床效果验证 |
| 工具/框架开发 | 设计需求、来源、开发过程、适用对象及实际验证范围；区分提出方案与验证效果 |
| 质性/混合方法 | 问题与方法匹配、取样、研究者角色、资料与分析、反思及混合部分如何整合 |
| 教学干预/课程实践 | 目标、内容、实施强度、任务衔接、教师与学员角色、评价层次及真实学习证据 |
| 质量改进/实施研究 | 场景、干预过程、时间变化、过程与结局指标、背景因素及持续调整 |
| 方案/申报书 | 问题、设计、可行性、预设结局、分析和实施计划；已完成与拟开展内容分开 |

## 统计与数字

检查统计方法与设计、变量、分析单位、配对、重复测量及聚类关系是否匹配。核查模型假设、协变量依据、过拟合、缺失、多重比较和探索性分析。需要何种方法取决于实际设计，不能给所有稿件统一要求正态性检验、α、事后功效或样本量公式。

用已提供数字检查总计、百分比、分母、均值与离散程度及取整。只有材料支持时才复算；条件不足就列所需信息，不制造精确 P 值或未执行分析。不显著不能证明等效，非劣效也不能改成无差异。

## 医学教育与 AI 教学

辨明教育理论或框架承担目标、设计、解释还是测量用途，不要求为了装饰强加理论名称。满意度、自我感知、提交作品、客观学习、临床行为和患者结局分别需要相应材料。

说明学员、教师、课程、班级、作品和评分条目的关系；条目行数不能自动当作独立样本数。核查评分者、盲法、量表、重复评分及与设计相符的信度指标。

对师生权力关系、考核公平、录音录像与二次分析，核对实际授权和隐私保护。AI 系统需要与研究主张相关的模型、版本、资料来源、提示或任务、教师核验和输出评价；不因平台技术不可见就补造参数，也不把感知可信度写成客观正确率。

## Word 与视觉材料

读取正文、表格、脚注、图注、参考文献、批注、修订和补充材料。批注台账保留位置、意图、依据和处理状态，不能将批注当作已核实事实；修回时维护历轮有效问题。

可检查 OOXML 中批注、关系、图片和样式；提取不到的内容需补做相应识别或视觉核对。图片文件像素数须结合实际显示尺寸、矢量形式及稿约判断，不单靠文件元数据断定印刷质量。表格边框或空样式属于具体检查线索，不能未经渲染声称页面存在问题。

## 伦理、利益关系与领域边界

核对本次适用的伦理、豁免和同意要求，不能一概断言所有病例都必须取得某一种审批形式。缺少报告时要求补充依据，不直接定性违规。

作者自研工具或方法可提示需要了解知识产权、商业、资金、任职及其他利益关系；自研本身不自动证明存在利益冲突，也不能忽略真实关系。通信作者数量、署名与格式以适用稿约为准。

技术或术式选择的评价说明实际材料与文献依据，保留需领域专家判断的部分；领域问题和其他可核项目都不因 AI 生成而获得额外确定性。
