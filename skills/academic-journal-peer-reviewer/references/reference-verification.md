# 著录与引用主张核验

将参考文献著录、可访问全文和特定主张支持分别核查。数据库记录、DOI 可解析与全文支持不互相替代；检索失败也不等于伪造。

## 1 范围与网络使用

先从稿件建立参考文献及正文引用位置清单。全面审稿逐条登记著录处理状态，可分批进行；用户指定局部或专项时按该范围执行。主张层优先覆盖主要结论、方法来源、关键数值和疑似错配，记录实际覆盖分子、分母及未查部分。

核验使用期刊或出版社页面、DOI 注册元数据、PubMed、原始报告和可合法获得的全文。只有主题相关或元数据命中时不能声称核实原文。引用核查不要求同一关键词必须逐字出现，需阅读相关语境、同义概念和研究设计。

按当前任务授权发送最少 DOI、题名或公开书目信息，不上传整稿、保密批注、患者资料或私人审稿报告。用户只要求离线检查时不联网。外部模型复核、IMA 归档和向作者或编辑发送均需各自明确授权。

## 2 3A 著录层

逐条检查题名、作者、刊物、年份、卷期页码或文章号、DOI 等字段；查对来源并记录差异。在线优先与印刷年份、版本和勘误可能造成字段差异，先定位原因，不能直接判假。可获取时核对出版社的勘误、撤稿或关注声明，并把文献事件与著录、访问及引用支持状态分别记录，不重复混入互斥计数。缺 DOI 的合法文献按其文献类型查证，不强行补造。

| 状态 | 可以说明什么 | 仍不能说明什么 |
|---|---|---|
| metadata-only | 已获取某数据库元数据 | 该记录与稿件著录完全匹配、原文已读、引用支持 |
| metadata-match | 记录与稿件著录在已核字段匹配，列明来源与字段 | 原文支持稿件主张或研究有效 |
| bibliographic-mismatch | 某些已核字段不一致 | 差异原因或伪造结论 |
| crossref-not-found | 本次在 Crossref 未取到该 DOI 记录 | DOI 不存在、文章伪造或其他注册机构未收录 |
| lookup-error | 网络、限流、解析或服务错误 | 已完成文献核查 |
| unverified | 尚未核查或材料不可得 | 文献真实或不真实 |

可选 `scripts/batch_doi_verify.py` 仅查询 Crossref 元数据，支持 `--doi` 或 `--doi-list` 和 `--output`。它不做全文阅读、题名语义判断或主张支持裁决；输出不能直接改名为 verified。命中后仍需把真实字段与稿件著录逐项比较。

Crossref 的接口用途与跨注册机构元数据获取方式见其[官方文档](https://www.crossref.org/documentation/retrieve-metadata/)。本脚本只使用 Crossref 单一查询结果，不把它外推成所有 DOI 或所有文献的完整覆盖。

## 3 3B 主张支持

建立表：正文位置与短原句、所引来源、已读范围、原文相关证据、判定、修改建议。区分来源自身发现、对其他研究的转述、作者解释与未解决问题；必要时回溯真正原始出处。综述、指南和共识可以支持与其文献类型相符的主张，不一律改为原始研究。

| 状态 | 判定依据 |
|---|---|
| verified-supports | 已读足以判断的原文部分，直接支持本次主张及其范围 |
| verified-partial | 只支持部分条件、对象或子主张，明确差别 |
| verified-mismatch | 已读材料与方向、数值、对象、设计、归因或推断类型不符 |
| unverified | 未读到足够内容或仍有疑问；不能根据题名猜测 |

核对方向、效应量、置信区间、分母、统计显著性、主要与次要结局、研究人群、时间和完成状态。非劣效、等效和未检出差异有不同的设计与含义，不能互换。作者自引与普通引文使用同一标准。

关键词出现不是支持的充分条件，未逐字出现也不是不支持的充分条件。多文献共同引用须明确每篇支持哪部分，不把不同研究拼成未验证因果链。旧状态码按原始核查证据重新判断，不能把“存在性已查”直接映射为“主张已核实”。

## 4 报告与疑点

分别报告著录总数、已处理数、匹配数、差异、未检得、工具错误和未查数；主张层另报实际核查范围。分母不足或部分失败时保留未完成状态，不用“全部真实”概括全文引用。

发现可核的不一致时定位字段及来源，先建议更正或补材料。只有不足的检索证据时写明尚不能判断；疑似完整性问题交审稿人和编辑核实，不定性不端。记录含私人信息时保存在非公开工作目录。
