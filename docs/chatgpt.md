# 在 ChatGPT 中使用

版本 **1.1.0**。按当前账户和宿主实际支持的技能、插件或会话附件方式提供本包。本文不假设统一的安装界面。

## 提供技能文件

| 宿主能力 | 使用方法 |
| --- | --- |
| 支持安装独立技能 | 使用单技能 ZIP，按宿主提示安装自包含目录。 |
| 支持导入便携插件 | 使用插件 ZIP，保留根 `plugin.json` 和 `skills/` 结构。 |
| 只支持本次会话附件 | 上传技能包或可接受的解压文件，要求先读取主技能与参考文件。 |

云端会话使用本次可访问的附件和工具；本机 Codex 安装目录需要另行提供给会话。公开 GitHub 源码、下载 ZIP 和在账户中完成安装是不同步骤。

单技能包目录名为 `academic-journal-peer-reviewer/`；插件中的主文件为 `skills/academic-journal-peer-reviewer/SKILL.md`。先定位这个文件，再按相对路径读取参考材料。脚本和共同表达规则随技能提供。

## 开始一轮审稿

先提供最新完整稿、图表和补充材料。目标期刊要求、前轮意见和作者回复按任务加入。可发送：

```text
请使用附件中的 academic-journal-peer-reviewer 1.1.0 审阅本稿。
先读取 SKILL.md、references/anti-defensive-gate.md 和本次模式所需参考文件。
完整阅读可获得材料，说明覆盖范围；按实际设计检查问题、方法、统计与报告规范。
请给出中文报告，每项意见包含位置、证据、影响和具体改法。
文献元数据与引用主张支持分别核验，缺少原文或未执行的部分明确列出。
先完成本地审查；外部检索等我授权。原稿保留，另交意见文件。
```

只有摘要或局部内容时，审查限于这些材料。英文稿的报告语言按用户要求；全篇双语报告可另加“请将全部意见按中英对照输出”。

修回核查可发送：

```text
请核查原意见、作者回复和修回正文。
逐条记录作者声称、实际位置、证据、解决状态和剩余问题。
检查回复是否在原问题所在层级解决了问题，并核查新增内容。
```

## 联网授权与正式审稿保密

按期刊的保密和 AI 使用要求提供审稿材料。联网查询须获得本次授权，并先使用 DOI、PMID、题名等最少必要元数据。上传全文、私人批注或可识别资料到外部服务前，须另行确认具体内容和服务。IMA 归档、投稿系统填写及对外发送同样需要授权。

能够检索文献记录时，先记录 3A 著录状态；取得相关原文并完成上下文核对后，才给出 3B 主张支持判断。全文不可得、来源冲突和未执行的核查各自列明。

## 运行随包门控

有 Python 且包内文件可访问时，使用技能中的 `scripts/writing_gate.py`。最终报告保存为 UTF-8 文本后，运行 `prepare`，阅读全文、逐项处理候选并完成语义审查，再运行 `check`。与最终文本对应的报告为 `PASS` 且退出码为 0 时，完成本技能的交付流程；正文再改需重查。

没有 Python 或无法访问脚本时，说明具体缺口，继续材料阅读与审查准备，再到能够执行的环境完成门控。PASS 反映候选处理和审查记录满足要求；审稿准确性和科学判断须依据所读材料与独立评估。

门控指南见 [references/anti-defensive-gate.md](../skills/academic-journal-peer-reviewer/references/anti-defensive-gate.md)。审查记录、稿件和作者回复放在私人工作位置，公开发行包只包含通用规则和工具。
