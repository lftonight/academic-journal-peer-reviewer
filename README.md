# 学术期刊审稿 · Academic Journal Peer Reviewer

版本 **1.1.0** · **2026-10-18** · [English](README_EN.md) · [Codex](docs/codex.md) · [ChatGPT](docs/chatgpt.md)

用于常规医学、医学教育、中文核心及 SCI/SCIE/SSCI 稿件的审稿辅助。读取完整稿件后，按研究问题、设计与统计、论据、语言和体例提出可定位、可执行的意见。

本版以用户提供的 v1.0.0 为材料，保留四道横切检查、角色分工、两层文献核验和修回核查架构，修正机械大修、跨设计套用清单、证据判断过度确定及外送流程。比较依据是技能文本和规则应用演练，尚未实施真实稿件的对照效果评价。

## 审什么

- **问题与论证**：先判断核心问题、章节和段落功能，再核对主张与证据，最后处理语言及格式。
- **设计与统计**：按实际研究设计检查样本、测量、偏倚、分析、效应量与不确定性；适用条目才列为要求。
- **报告规范**：选择对应规范及扩展，核对作者清单、稿件位置和实际内容。
- **两层文献核验**：3A 核对文献记录与著录字段；3B 回到原文判断引用是否支持主张。元数据一致只说明著录核对结果。
- **证据保真**：保留对象、比较、数值、统计判断、负面结果和结论力度；审稿人的改写建议也受同一约束。
- **修回核查**：逐条核对原意见、作者回复和正文改动，识别只改语言却未解决原问题的情况。

问题层级与严重程度分别判断。局部段落或引用问题可以小修；影响主结论、研究有效性或需要大幅重建论证的问题再考虑大修。报告同时区分已核实、材料不足和无法核实的事项。

## 准备材料

优先提供最新完整稿、图表、补充材料、目标期刊要求；修回核查另提供前轮意见和作者回复。只有摘要或局部段落时，审查范围限于已提供内容。全文、原始数据或文献全文缺失时，报告列明缺口及其影响。

审稿默认只读，另交意见文件。正式审稿材料应符合期刊的保密和 AI 使用要求。联网前须有本次任务的明确授权；检索从 DOI、PMID、题名等最少必要元数据开始。全文、私人批注及可识别资料的外送须单独确认。IMA 归档和投稿系统填写由用户另行授权。

## 开始使用

下载并解压仓库，在根目录运行：

```text
python -X utf8 scripts/install_codex.py
```

安装器使用 Python 3.10 或更高版本，默认目标为 `CODEX_HOME/skills`，未设置时为用户目录下的 `.codex/skills`。更新先完整备份已有同名技能，覆盖公共文件并保留其他私人扩展；实际路径见安装输出。宿主发现方式见 [Codex 指南](docs/codex.md)。

```text
$academic-journal-peer-reviewer
请审阅最新完整稿，按常规医学教育论文标准提出中文意见。
先读取技能及门控文件，说明本轮材料覆盖，按适用设计检查方法、统计和报告规范。
请给出最关键的问题、位置、证据和可执行建议，并区分文献记录核验与引用主张核验。
本轮只做本地审阅，外部检索待我授权。
```

英文稿默认可按用户工作语言报告；需要全篇中英对照时明确提出。用户点名 ARS、Nature 或其他专门技能时，按其指定执行。ARS 的多角色反证、校准及全流程协作，Nature 的期刊定向评审继续保留各自用途。本版适合日常入口，效果优势仍需同稿盲评检验。

## 成品表达门控

技能内含规则、`writing_gate.py` 和测试，使用 Python 标准库离线运行。最终报告保存为 UTF-8 文本后，执行 `prepare`、实际语义审查、逐项处理候选，再执行 `check`；只有与最终文本对应的报告为 `PASS` 才完成该流程。正文变更后重查。

没有 Python 或脚本不可访问时，说明具体缺口，继续资料阅读与审查准备，再到可执行环境完成门控。PASS 表示候选及审查记录满足检查要求，科学判断、引文支持和审稿决定仍需各自的证据与人工评估。[门控指南](skills/academic-journal-peer-reviewer/references/anti-defensive-gate.md)
